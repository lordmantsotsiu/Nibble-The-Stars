# 🌌 Nibble the Stars

Welcome to **Nibble the Stars**, a cosmic twist on the classic snake game. Navigate the void, collect stars, and avoid biting yourself in this celestial arcade experience.

## 🔗 Live Demo
Play the game here: [https://lordmantsotsiu.github.io/Nibble-The-Stars/](https://lordmantsotsiu.github.io/Nibble-The-Stars/)

---

## 🎮 How to Play
*   **The Goal:** Navigate the grid to collect stars.
*   **The Mechanic:** Grow longer as you eat.
*   **The Challenge:** 
    *   The walls wrap around, allowing you to pass through them to the other side.
    *   **Crucial Rule:** The only way to end the journey is to bite your own tail!

## 🛠️ Features
*   **Retro Arcade Gameplay:** A nostalgic experience with a unique space-themed aesthetic.
*   **Wrap-Around Boundaries:** Forget standard borders; use the screen wrap to your advantage.
*   **Minimalist Design:** Clean interface built for smooth performance.

## 🚀 Built With
*   **HTML5 Canvas:** Used for rendering the game environment.
*   **JavaScript:** Powering the game logic and movement mechanics.
